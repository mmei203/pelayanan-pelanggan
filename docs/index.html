PERUMDA PALD - API Pelayanan Pelanggan

Dokumentasi resmi dan antarmuka pengujian interaktif untuk backend Sistem Pelayanan & Pengaduan Pelanggan PERUMDA PALD. Dibangun dengan Node.js, Express, Prisma ORM, dan MariaDB/MySQL.

1
Pelaporan Masuk
PENDING

Customer Service (CS) menerima laporan pelanggan dan mencatatnya melalui POST /api/pelanggan.

2
Penugasan Lapangan
ON PROGRESS

Operator ditugaskan untuk menangani pengaduan melalui PUT /api/pelanggan/{id} dengan menyertakan operatorId.

3
Penyelesaian Laporan
SELESAI

Operator menyelesaikan tugas dengan mengunggah bukti foto keluhan, dokumen laporan, dan koordinat GPS (lat, long).
